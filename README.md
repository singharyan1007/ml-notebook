# ML Notebook — Astro + GitHub Pages

A simple, static machine-learning knowledge base. Astro and Starlight supply Markdown pages, topic navigation, full-text Pagefind search, responsive mobile navigation, a table of contents, and a light/dark theme. No application server, database, or React runtime.

The four note bodies are preserved from the approved starter collection. They are representative reference summaries, not imported Obsidian writing or claims of course completion.

## Run locally

Use Node 24 (or a supported Node version >=22.23.4).

```bash
npm ci
npm run dev
```

Open the local address printed by Astro. The default base is `/ml-notebook/`.

To test the production search index:

```bash
npm run build
npm run check:links
npm run preview
```

Pagefind search is generated by the production build. It is not active in the development server.

## Add an Obsidian note

Copy selected notes into `src/content/docs/foundations/` or `src/content/docs/neural-networks/`. These are ordinary Markdown files and can be edited in Obsidian directly. Use this frontmatter:

```yaml
---
title: My next concept
description: One short sentence describing the note.
sidebar:
  order: 5
---
```

The topic sidebar is generated from the folders. The search index is rebuilt whenever the site is built. Do not copy the complete vault or unrelated private files.

Supports normal Markdown and `[[linear-regression|Linear regression]]` wiki links. When two files share a name, use the complete content path, e.g. `[[foundations/linear-regression|Linear regression]]`. Unknown or ambiguous wiki links fail the build. Fenced `formula` blocks display readable Unicode equations; LaTeX rendering and Obsidian embeds are not part of this small starter.

## Deploy on GitHub Pages

The workflow builds and deploys pushes to `master`. Pull requests are built and checked without deploying.

1. Push this project into the GitHub repository on `master`.
2. In **Settings → Pages**, choose **GitHub Actions** as the source.
3. Run **Build and deploy Astro** manually from the Actions tab, or push a note change.

The workflow derives `site` and `base` from `github.repository`, so it works with the final chosen repository name. A `USERNAME.github.io` repository uses the root path automatically. The configured project-site URL is `https://singharyan1007.github.io/ml-notebook/`. Deployment status is verified separately through GitHub Actions.

For a custom domain, override `SITE_URL` and set `SITE_BASE=/` in the build environment, and configure GitHub's custom domain settings.

## Editing and syncing

Once hosted, push Markdown changes to `master` to trigger a rebuild and deployment. An Obsidian Git workflow can sync this project, or copy only selected notes into `src/content/docs/`. No background vault sync has been connected by this project.

## Project structure

- `astro.config.mjs` — Astro, Starlight, sidebar, and GitHub Pages paths
- `src/content/docs/` — notes and overview
- `src/styles/custom.css` — a small reading-focused style adjustment
- `plugins/notebook-markdown.mjs` — wiki links and formula blocks
- `.github/workflows/deploy.yml` — build and approval-gated deployment
- `scripts/check-links.mjs` — checks generated internal links, headings, and assets

The existing private Sites deployment is separate and unchanged.
